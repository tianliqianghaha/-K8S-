# AI Infra 认知训练场

从机柜的插座，到线上的 SLA——把 AI 基础设施拆成 **7 个平面、28 个模块、85 个小关**，每一关都要动手，不是点点看。

打开即玩：**双击 `dist/index.html`**。不需要服务器，不需要装 Node。

---

## 这是什么

一个纯前端的知识训练场，覆盖 AI Infra 的七个平面：

```
L0 场地与物理    插座、机柜、线            M00-M01   2 个模块
L1 服务器与芯片  整机、PCIe、GPU、NVLink   M02-M05   4 个模块
L2 主机系统      内核、驱动、可见性、观测  M06-M09   4 个模块
L3 网络与通信    网卡、无损、拓扑、NCCL    M10-M14   5 个模块
L4 集群编排      K8s、调度、弹性、存储     M15-M19   5 个模块
L5 平台运营      成本、可观测、推理、容量  M20-M24   5 个模块
L6 性能与故障    归因、字典、压测验收      M25-M27   3 个模块
```

再加三个贯穿件：

```
X1 取证终端    28 条命令，输出全部来自当前关卡的现场
X2 故障注入台  24 个案卷，覆盖 L0-L5，走"现象 → 取证 → 根因 → 处置"
X3 能力雷达    七个平面的掌握度、下一步练哪、错题本
```

## 四种题型，不是四种选择题

```
A 还原   给零件、图或命令输出，摆对 / 连对 / 指对
B 诊断   给现象，选根因再选处置——必须能区分"同一现象在不同层的根因"
C 计算   带宽、时延、通信量、显存、MFU、成本，答案只由公式算出
D 决策   约束下选方案，存在真实取舍，用惩罚值给分而不是唯一解
```

判分不只说"这格对不上"，而是说**错在哪一层**：差在 NUMA 层、差在 PCIe 层、差在调度层。

## 三条内容原则

**一、不编造。** 终端输出必须来自当前关卡声明的现场。没有现场的关卡会明确写"下面是参考机型，不是题里的那台"，绝不假装。

**二、不越层。** 模块页只准出现本平面及以下的术语。在 GPU 架构那一页谈机柜 PDU 分路，算设计缺陷。

**三、现象里的数字必须查得到。** 案卷说"某张卡 DBE 是 3"，`nvidia-smi -q` 就必须显示 3；说"账单 516,096"，就必须等于卡时 × 单价。这条由测试逐条比对。

## 跑测试

```bash
node tests/engine.test.js     # M03 深度：模型、七种关系码、放置规则、四关可解
node tests/contract.test.js   # 28 模块 × 85 关 × 10 seed 的通用契约
node tests/console.test.js    # 终端：28 条命令、残缺现场不崩、与模型逐字节一致
node tests/ability.test.js    # 掌握度公式、推荐、错题本、脏数据
node tests/lab.test.js        # 24 个案卷结构、两段判定、证据一致性
```

浏览器端（Edge / Chrome 无头模式打开即可，结果输出在页面上）：

```
tests/ui.smoke.html   M03 逐项交互 + 终端 + 雷达
tests/ui.all.html     85 关真点一遍 + 24 卷深链 + 结算流程
```

## 构建

```bash
node build.js     # 生成 dist/index.html
```

构建只做一件事：把 `index.html` 里引用的 css 与脚本内联进去，用正则替换，零依赖。

## 一些实现上的取舍

```
为什么用原生 JS + UMD    要求装 Node 才能玩，等于把一半读者挡在门外
为什么数据类型分渲染器   加 28 个模块不用碰 renderers 一行代码
为什么测试遍历注册表     加模块不用改测试，新模块自动被契约测试覆盖
为什么案卷单独成库       终端是工具，案卷是题库；加案卷只写数据，不碰终端
```

## 已知边界

- 没有移动端适配，最小可用宽度约 1180px（再窄会堆叠成单列）
- 终端是模拟器：命令集合与输出格式贴近真机，但不会真的执行任何东西
- X2 的案卷是"证据齐全"的理想情况，真实排障里证据常常缺失一半
- 成绩只存在本机 localStorage，换机器不同步
