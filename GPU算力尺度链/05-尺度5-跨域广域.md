# 尺度 5 · 跨域广域（算力网络）

## 0. 本篇对象

> **原样题面**：按照这种从小到大的尺度，给我每个尺度详细介绍一下。我的中心是学习。你要给我介绍学习的重点。比如学传统网络的最大重心就是 IP 和路由，像这种形式，你在每个层级章节把重心罗列并且详细讲解。

**本篇讲尺度链第 5 格：跨数据中心、跨地域、跨云的算力互联与调度。** 主角是算力路由、确定性网络、算网大脑。这是尺度链的顶端，也是"算力网络"这个词真正所指的东西。

---

## 1. 学习重心（先罗列）

对标"学传统网络 = 学 IP + 学路由"：

```text
学算力网络 = 学「算力路由」 + 学「确定性」

重心一：算力路由 —— 路由的依据从"目的地址"变成"哪有合适算力"
重心二：确定性   —— 让跨域传输的时延、抖动、丢包可承诺

其余都是配角：
  SRv6        —— 实现确定性可编程路径的协议
  算力标识     —— 让算力可寻址的基础
  算网大脑     —— 做联合决策的系统
  东数西算     —— 国家工程的名字，算力网络是它的底座
```

**为什么是这两个**：因为你学传统网络时抓的"IP + 路由"，在这里正好被替换掉了——**IP 变成了算力标识，路由变成了算力路由**。这就是算力网络与传统网络的分水岭。而跨域之后距离变长、链路变复杂，"尽力而为"不够用了，必须上确定性。这两个抓住了，这一层的所有名词都能归位。

---

## 2. 重心一详解：算力路由

### 2.1 核心直觉：路由的对象变了

```text
传统网络路由：
  问"这个包要去哪个地址？" → 查路由表 → 选一跳
  决策依据：目的 IP 地址、链路开销

算力网络路由：
  问"这个任务该去哪座算力？" → 查算力目录 → 选节点 + 选路径
  决策依据：哪有空闲算力、哪电价低、哪时延满足 SLA
```

**这就是最本质的变化**：网络不再只是"搬运工"，它开始**理解算力**。路由表里装的不再是静态的地址前缀，而是动态的算力状态。

### 2.2 算力路由的三块基础

```text
算力标识 —— 让算力可寻址
  每一份算力要有统一的名字和属性描述（在哪、什么类型、多少、什么状态）
  没有标识，就没法"找算力"，就像没有 IP 就没法上网

算力目录 / 一本账 —— 让算力可见
  全国/全域的算力资源登记、状态汇总
  "1+M+N"节点体系：1 个国家节点 + M 个区域节点 + N 个行业节点

联合决策 —— 算力 + 网络一起选
  传统做法：调度归调度，网络归网络，两张皮
  真正成熟的做法：一次决策里同时算"选哪个算力 + 走哪条链路 + 电价多少 + SLA 够不够"
```

### 2.3 学到什么程度算掌握

```text
能回答：算力路由和传统路由的本质区别（决策依据不同）
能解释：为什么算力标识是前提（不可寻址就不可调度）
能说清："算网大脑"到底在算什么（算力+网络的联合最优）
能理解：为什么"电价""绿电"会进入网络决策（算电协同）
```

## 3. 重心二详解：确定性

### 3.1 核心直觉：跨域之后，"尽力而为"不够了

局域网里距离短，网络抖动影响不大。跨域之后，几千公里、经过无数跳，问题来了：

```text
传统网络的承诺："我尽力送，丢了重传，堵了就慢点"
训练/推理的诉求："我要求这个包 5ms 内到、抖动不超过多少、基本不丢"
```

因为跨域训练是**同步的**：一个跨地域的梯度同步慢了，整个训练卡住。所以必须把网络从"尽力而为"改造成"可承诺"。

### 3.2 确定性靠什么实现

```text
SRv6 —— 可编程路径
  基于 IPv6，把路径、节点、网络功能编成一条可执行的转发指令
  可以按"时延最低""带宽最大""可靠性最高"为不同任务选不同路径
  关键新动向：SRv6 正从"算力中心之间"往"算力中心内部"延伸，
  用 uSID 把路径能力下沉到网卡/DPU

网络切片 —— 逻辑隔离
  在同一张物理网上切出多张逻辑网，各业务互不干扰
  训练流量不会被网页流量挤占

随流检测 —— 看得见质量
  对每个流实时监测时延、丢包、抖动
  没有测量，就谈不上"承诺"

三级时延圈
  1ms / 5ms / 20ms 的分层布局
  东部需求接西部算力，靠的就是毫秒级的确定性链路
```

### 3.3 学到什么程度算掌握

```text
能回答：确定性网络承诺的是什么（时延、抖动、丢包可量化）
能解释：SRv6 为什么叫"可编程路径"，它比传统路由强在哪
能理解：网络切片和随流检测各自解决什么问题
能说清：为什么"东数西训"必须建立在确定性网络上
```

## 4. 八问展开

```text
【是什么】
  跨地域、跨数据中心的算力互联与调度。算力网络（Computing Power Network）。

【物理边界】
  管：跨域的算力连接、调度、交易
  不管：单集群内怎么算、怎么同步（那是尺度 1–3 的事）

【跨哪道鸿沟】
  分散的算力孤岛 ↔ 全国统一调度的算力服务。
  没有这一格，东部的算力需求用不上西部的绿电算力。

【内部构成】
  连接：SRv6 骨干网、确定性网络、光底座（400G/800G）
  可寻址：算力标识、1+M+N 节点体系
  决策：算网大脑、算力路由
  服务：算力交易、算电协同、算力超市

【对上给什么 / 对下藏什么】
  对上给：像水电一样按需取用的算力服务
  对下藏：地理位置、芯片型号、链路细节、电力来源

【概念归位】
  算力路由   = 重心一（路由对象变了，这是与传统网络的分水岭）
  确定性     = 重心二（跨域传输可承诺）
  算力标识   = 可寻址的基础（对应传统网络的 IP）
  算网大脑   = 决策系统
  东数西算   = 国家工程；算力网络 = 它的技术底座

【现在咋样 + 怎么用】
  现状：2026 年算力网纳入国家"六张网"，与水网、电网并列
  数据：八大枢纽间 145 条干线光缆，各省至枢纽时延降至 20ms 内
  用法：跨地域训练、跨域推理、算力交易、绿电调度

【为什么不能省 + 交接点】
  没有这一格：全国算力是一盘散沙，西部绿电用不上，东部需求接不住
  交接点：回到尺度 4 —— 任务被调度到某个数据中心后，由本层接手池化与调度
```

## 5. 本篇小结

```text
一句话记住：算力网络 = 算力路由 + 确定性

算力路由回答"去哪座算力"：标识 → 目录 → 联合决策
确定性回答"怎么稳稳送到"：SRv6 可编程路径 + 切片 + 随流检测

最容易踩的坑：把算力网络理解成"更快的网"——它不是修网，是让网懂算力
最该建立的直觉：传统网络的 IP+路由，在这里变成了算力标识+算力路由
                这一替换，就是整个算力网络的概念核心
```
