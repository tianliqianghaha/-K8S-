# 02 · 第 2 章 云端控制面 + 节点入集群

> 本章目标：云上起一台控制面，把第 1 章的本地 GPU 节点真正注册进来，
> 让 `nvidia.com/gpu` 出现在调度器的 Capacity 里。
> 前置条件：第 1 章三道闸门全过。

---

## 一、开机器

用 `aliyun-ecs-one-liner` 技能，自定义模板 `hk-ai-cp.template.json`（见 `~/.workbuddy/skills/aliyun-ecs-one-liner/assets/`）：

```
规格       ecs.e-c1m2.xlarge（4C8G）× 1
地域可用区  cn-hongkong / cn-hongkong-c
计费       按量 + 抢占（SpotAsPriceGo，无保护期）
镜像       ubuntu_26_04_x64_20G_alibase（24.04 只有带驱动的 100G 变体，控制面不需要）
系统盘     100 GiB ESSD entry，随实例释放
公网       按流量，峰值 100 Mbps
自动释放   12 小时后兜底
```

三步走（脚本在 `~/.workbuddy/skills/aliyun-ecs-one-liner/`，先 cd 过去）：

```bash
cd ~/.workbuddy/skills/aliyun-ecs-one-liner

python3 scripts/cli.py --template assets/hk-ai-cp.template.json preflight   # 体检账号与资源
python3 scripts/cli.py --template assets/hk-ai-cp.template.json plan        # 询价 + DryRun，出确认卡
python3 scripts/cli.py --template assets/hk-ai-cp.template.json create --confirm <四位令牌>
```

预期：约 50 秒到 Running，拿到公网 IP，凭据落在 `state/credentials/<实例名>.txt`。

安全组需要额外放行（只对本机出口 IP，不向全网开放）：

```
6443     kube-apiserver（本地节点要连）
10250    kubelet（云端排障用）
31154    Envoy Gateway 入口（第 3 章）
```

## 二、装控制面

登录后依次执行：

```bash
# 1. 基础依赖
apt-get update -qq
apt-get install -y -qq containerd curl gnupg apt-transport-https ca-certificates

# 2. containerd 开启 SystemdCgroup
mkdir -p /etc/containerd
containerd config default > /etc/containerd/config.toml
sed -i 's/SystemdCgroup = false/SystemdCgroup = true/' /etc/containerd/config.toml
systemctl restart containerd && systemctl enable containerd

# 3. 关 swap
swapoff -a && sed -i '/swap/s/^/#/' /etc/fstab

# 4. 内核参数
cat > /etc/modules-load.d/k8s.conf <<'EOF'
overlay
br_netfilter
EOF
modprobe overlay && modprobe br_netfilter
cat > /etc/sysctl.d/k8s.conf <<'EOF'
net.bridge.bridge-nf-call-iptables  = 1
net.bridge.bridge-nf-call-ip6tables = 1
net.ipv4.ip_forward                 = 1
EOF
sysctl --system

# 5. kubeadm / kubelet / kubectl 1.37.2
curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.37/deb/Release.key | gpg --dearmor -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg
echo 'deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.37/deb/ /' > /etc/apt/sources.list.d/kubernetes.list
apt-get update -qq && apt-get install -y -qq kubelet kubeadm kubectl
apt-mark hold kubelet kubeadm kubectl
```

初始化（单节点，所以直接绑私网 IP）：

```bash
kubeadm init \
  --apiserver-advertise-address=172.23.163.98 \
  --apiserver-cert-extra-sans=47.238.160.73 \
  --pod-network-cidr=10.244.0.0/16 \
  --node-name=ai-cp-1

mkdir -p $HOME/.kube && cp /etc/kubernetes/admin.conf $HOME/.kube/config
```

**第一件必须做的小事**：去掉控制面 taint。

```bash
kubectl taint nodes ai-cp-1 node-role.kubernetes.io/control-plane-
```

单节点集群如果不去掉，后面 Envoy Gateway 的 certgen、监控组件全部会 Pending。

## 三、装 Cilium（数据面 + 代替 kube-proxy）

```bash
helm repo add cilium https://helm.cilium.io
helm install cilium cilium/cilium --version 1.20.4 -n kube-system \
  --set kubeProxyReplacement=true \
  --set k8sServiceHost=172.23.163.98 \
  --set k8sServicePort=6443 \
  --set ipam.mode=cluster-pool \
  --set ipam.operator.clusterPoolIPv4PodCIDRList=10.244.0.0/16 \
  --set operator.replicas=1 \
  --wait --timeout 6m
```

验收：

```bash
kubectl -n kube-system get pods -l k8s-app=cilium
kubectl get node ai-cp-1          # 应变 Ready
cilium status --wait              # 需先装 cilium CLI，或看 pod 日志
```

预期：`cilium status: OK`，且 kube-system 里**没有 kube-proxy**。

## 四、把本地 GPU 节点注册进来

### 4.1 云端拉起 device plugin（先让集群认识 GPU 这种资源）

```bash
kubectl apply -f https://raw.githubusercontent.com/NVIDIA/k8s-device-plugin/v0.17.4/deployments/nvidia-device-plugin.yml
```

如果 GitHub 不通，从能通的机器上 `kubectl get ds nvidia-device-plugin-daemonset -n kube-system -o yaml` 导出再 apply。
镜像 `nvcr.io/nvidia/k8s-device-plugin:v0.17.4` 国内拉不到时，走云端中转：云端拉取 → `ctr export` → `scp` → 本地 `ctr import`。

DaemonSet 必须限定只跑在 GPU 节点：

```bash
kubectl -n kube-system patch ds nvidia-device-plugin-daemonset --type=merge \
  -p '{"spec":{"template":{"spec":{"nodeSelector":{"kubernetes.io/hostname":"ai-gpu-1"}}}}}'
```

### 4.2 本地节点 join

在**云端**生成加入命令：

```bash
kubeadm token create --print-join-command
```

在**本地 WSL** 执行（`--node-labels` 在 1.37 已移除，标签要在配置文件里给，或者 join 后用 kubectl 补）：

```bash
sudo kubeadm join 47.238.160.73:6443 --token <token> \
  --discovery-token-ca-cert-hash sha256:<hash>
```

如果 join 失败，清理残渣再重试：

```bash
sudo kubeadm reset -f
sudo rm -rf /etc/kubernetes/pki/ca.crt /var/lib/kubelet/kubeadm-flags.env
sudo systemctl restart kubelet
```

### 4.3 给 GPU 节点打 taint

```bash
kubectl taint nodes ai-gpu-1 nvidia.com/gpu=present:NoSchedule
```

## 六、本章刻意不做的事

```
不装 Ingress / Gateway      属第 3 章（Envoy Gateway 是实验一的一部分）
不装任何监控               属第 5 章，且必须调参后才能装（低配云盘会被压死）
不在本地节点装 CNI           这是刻意的设计：GPU Pod 一律 hostNetwork
不把 vLLM 放进 K8S          推理服务用 systemd 托管（理由见第 6 章经验）
```
