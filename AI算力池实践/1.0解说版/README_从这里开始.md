# AI 算力池实践 1.0 · 解说版（讲给初级人员）

这套解说版回答一个问题：**原资料（《AI算力池实践/1.0》，8 册搭建文档 + 脚本 + 踩坑记录）里出现的每一个东西，到底是干什么的、为什么必须有它。**

讲解口径和样板一致：每个东西先用大白话讲"它是什么"，再讲"为什么必须有它 / 不做会怎样"，每章末尾附"判官卡（当时为什么这么选）"和"坑（现象 / 根因 / 怎么防）"。

## 三个贯穿全册的核心概念（初级人员先记住这三条）

```
① 反连负责把任务送到卡上，K8S 负责裁决谁有资格用卡
   这是两套接入方式并存的原因，不是重复建设。

② 每一步只引入一类新变量
   先链路（第 3 章）→ 再调度（第 4 章）→ 最后治理（第 5 章）。
   出问题范围可控，是这套实验最重要的纪律。

③ 每个能力都必须有一个数
   "装了 KEDA"不算，"队列积压 → 副本 0 变 4、1 Running 3 Pending"才算。
   CPU 和内存不算信号；GPU 看显存和温度，控制面看 etcd 落盘耗时。
```
