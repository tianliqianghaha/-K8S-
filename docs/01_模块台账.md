# 模块台账

> 规则：一个模块只有走完「设计 → 实现 → 自测 → 挑错 → 优化 → 定稿」六步，状态才允许改成 `定稿`。
> 状态取值：`待开工` / `设计中` / `实现中` / `自测中` / `挑错中` / `优化中` / `定稿`
> 台账只增不改结论——被推翻的判断要留痕，写明哪一轮、为什么推翻。
