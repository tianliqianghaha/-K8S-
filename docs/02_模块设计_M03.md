## 二、认知点清单（少一个都算没讲到）

```
1  PCIe 是一棵树，不是一张网
   CPU 根端口 → Host Bridge → 桥 → 交换芯片 → 设备。没有环路，只能一层层往上走再下来。

2  七个关系码的判定顺序
   先看是不是自己（X）→ 再看有没有 NVLink（NV#）→ 再看 NUMA（SYS）
   → 再看桥（NODE）→ 再看交换芯片路径（PIX / PXB / PHB）→ 最后路径缺失（?）
   顺序不能换：NVLink 优先于 NUMA，所以两张卡在两个 NUMA 里照样是 NV8。

3  跳数不等于掉带宽
   这是全模块最想纠正的误解。PCIe 交换芯片是非阻塞的，
   多过一颗交换机主要加延迟（百纳秒级），不直接降带宽。
   真正掉带宽的只有三件事：跨 NUMA、链路降代（Gen5→Gen4）、链路宽度砍半（x16→x8）。

4  带宽口径
   Gen5 x16：单向 32 GB/s，双向 64 GB/s。题目里所有时间计算一律用单向。
   400G 网卡 = 400 Gbps = 50 GB/s。这两套单位混用是新手第一大坑。

5  网卡插哪一路，决定一半的卡跨不跨 NUMA
   8 卡双路机，GPU0-3 在 NUMA0、GPU4-7 在 NUMA1。
   NIC0 插 NUMA0、NIC1 插 NUMA1，每张卡都就近；
   两张网卡都插 NUMA0，NUMA1 那四张卡每发一个包都要过 UPI。
```

## 三、四个关卡（stage）的设计

```
s1 · A 还原型 · renderer=board
   题面：nvidia-smi topo -m 的完整输出（含图例）+ lscpu 的 NUMA 段
   操作：把 12~16 个零件（CPU / 桥 / 交换芯片 / GPU / 网卡）拖进层级框
   判定：player 反算出的矩阵与题面矩阵逐格比对，差异为 0 才过
   难度：easy = 4 卡双路（12 个零件）；hard = 8 卡双路（16~17 个零件）
   干扰点：桥上的设备可直连（产生 PHB）；交换芯片可两层嵌套（产生 PXB）；网卡可能整组挂错路（产生 SYS）

s2 · C 计算型 · renderer=calc
   题面：给拓扑 + 链路规格（Gen5 x16 / 被降到 Gen4 x16 / 跨 NUMA 效率 40%）
   问：搬 S GB 要多久（ms）
   判定：由公式算，容差 0.5%；题面参数即全部已知条件，禁止写死答案
   三个模板：
     T1 单链路传输时间 = S / 32 * 1000
     T2 降代后传输时间 = S / 16 * 1000（Gen4 x16 单向 16 GB/s）
     T3 两条路径耗时差 = S/12*1000 - S/32*1000（跨 NUMA 12 GB/s 为题面给定）
   陷阱：把双向 64 GB/s 当单向用，算出来正好差一半 —— 错得"很整齐"，必须能逮住

s3 · B 诊断型 · renderer=choice
   题面：topo 矩阵片段 + p2pBandwidthLatencyTest 输出 + 一句现象
   操作：从 4 个根因里选 1 个
   判定：单选，选中即给全部解析；错项的 why 必须说清"为什么不成立"
   四种案情（按 seed 出）：
     case1 矩阵 SYS + P2P 11.8 GB/s  → 跨 NUMA，过 UPI 转发
     case2 矩阵 PIX + P2P 3.1 GB/s   → IOMMU/ACS 把 P2P 拦成 CPU 中转
     case3 矩阵 PIX + P2P 正常 + 训练仍慢 → 瓶颈不在 P2P（干扰项辨析，指向 M05）
     case4 矩阵 PHB + P2P 18 GB/s    → 一方直连根端口，跨 Host Bridge

s4 · D 决策型 · renderer=choice
   题面：一台待装机（2 CPU / 4 桥 / 8 卡 / 2 张 400G 网卡），要跑 8 卡数据并行
   操作：从 4 个装机方案里选 1 个
   判定：用惩罚值（PIX 0 / PXB 1 / PHB 2 / NODE 3 / SYS 6）累加 8 张卡到其就近网卡的距离
         最优方案 penalty=0 得满分；多 1~3 半分并说明代价；≥6 判错
   要点：允许"次优但合理"的答案，这是 D 型与 A 型的根本区别
```

## 五、判定口径（写死，不许临场改）

```
s1  差异数 === 0 → 过。差异要按"关系码 → 层级"翻译成中文，指出错在第几对设备。
    不判零件标签（S0/S1 谁是谁），只判设备两两之间的关系。理由：
    标签是人为命名，拓扑才是事实，逼玩家猜标签属于无效难度。

s2  相对误差 <= 0.5% → 过。答案只能由公式函数算出，题面不出现答案数字。

s3  单选，选中即结算。错项也必须给出"为什么这个根因解释不了现象"。

s4  penalty(chosen) <= penalty(best) + 0 → 满分
    penalty(chosen) <= penalty(best) + 3 → 半分（记为"次优"）
    否则 → 错，并给出最优方案差在哪
```

## 六、题面真实度要求

```
topo 矩阵  必须与 `nvidia-smi topo -m` 的列宽、图例文字、码值一致
lscpu     必须出现 NUMA node(s) / Socket(s) / NUMA nodeN CPU(s) 三段
p2p 输出  必须带 Device-to-Device 的表头与 GB/s 单位
显存写法  81920MiB，不写 80G
```
