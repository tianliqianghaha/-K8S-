## 核心大坑（4 条，每条三行封顶）

```
现象：探针二加完 IP，对端 ping 100% 丢包
根因：阿里云 VPC 不转发未分配 IP 的 ARP，自建 VIP 在云上天然不可用
防：A3 先跑，不通直接上 HAVIP，别在 keepalived 上耗

现象：装 containerd 时 apt 报 Unable to locate package containerd
根因：新机器 apt 索引没更新，且 26.04 源的包名是 containerd 不是 containerd.io
防：install 前先 apt-get update，包名按 resolute 源实际叫法（见 03 章）

现象：第 4 章关掉一台 worker，副本一直 degraded 不重建
根因：数据盘被 3 副本卷吃满，没有单节点 20G 空间接新副本
防：C3 的容量账先算清（71G 卷 × 3 副本），或提前加盘

现象：init 后 worker join 报 x509，报错不提证书
根因：certSANs 漏了 VIP，apiserver 证书里没有 172.23.163.97
防：init 前按上面那张纸逐项核对 SAN 清单
```
